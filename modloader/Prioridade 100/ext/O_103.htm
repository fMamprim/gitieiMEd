Editor

Here you can change the IDE settings.

These lists set the colors of the various parts of the editor.

Active line: a color of the line where the cursor is.

Gutter: a color of the left edge of the editor

Editor: a color of the text background

The looking depth is used while making the list of missions, labels, variables, etc by pressing Ctrl + [space]. The number here means how much lines are scanned up and down from the place where the list called. If you set the number of 0, the program searches mentioned elements through the whole source file.

Also, you may set if the list will be shown automatically or not. If the box is checked, the list is called automatically after typing symbols @, $, #, etc.

There are the common editor options.

Show main panel – you may show or hide the main toolbar.

Show opcode info – by selecting this you made the editor to display different kind of information about the current opcode in the status bar (the number of the parameters, model ID, variable type, etc).

Line numbers – there will be the line numbers in the left gutter.

Show gutter border – by selecting it the left gutter will have the border line on the right side. Uncheck this box, if you want to increase the editor space visually.

Load last closed file at startup – when starting the program will open the last closed file being existed.

Load all closed files – you may open all closed files at startup. This option is only valid when the Load last closed file at startup checked.

Confirm when exit – at closing the program, you need to confirm it. It’s made to prevent occasional program exit.

Here you can choose the font and tune it. Sanny Builder supports only fixed-pitch fonts. The line AaBbCcDd displays the current settings.
