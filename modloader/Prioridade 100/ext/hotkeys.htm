Hotkeys

Apart from the standard hotkeys, (Ctrl + C, Ctrl + Z) the following also work:

TAB , Shift+TAB  move the selected text to the left / right (tab)
Ctrl + Alt + A / D  move the selected text to the left / right
 (by one symbol)
Ctrl + Alt + B / N / M  different modes of text selection: Normal, Columnar
 (same as selection with fixed Alt), Lines
Ctrl + Shift + B  jump between brackets: {}, (), <>, []
Ctrl + Shift + Num8 / Num2  to scroll page on line up / down
Ctrl + Scroll Up / Down  page up / down
Ctrl + Shift + U / L  make word uppercase / lowercase
Ctrl + T  delete word
Ctrl + Y  delete line
Ctrl + Shift + Y  clear line
Ctrl+Shift+V  enclose the selected text to the directives
 $VERSION  and $VERSION_RESTORE.
Ctrl + [space]  to show the list ofclasses/class members/models
 /labels/variables/missions
Ctrl + Shift + [space]  to show help for the current command of a class
Ctrl + Shift + C  insert player's coords
Ctrl + Shift + E  insert player's z_angle
Ctrl + Enter  open file at cursor (see also relative path priorities)
Alt + S  (when the list of models is active) re-sort the list
F1  search opcode with word at cursor
 (with ignoring of '_' and '.')
Ctrl + F1  search opcode with word at cursor
 (without ignoring of '_' è '.')
F2  use macros
Ctrl + J  show list of macros
Ctrl + M  start/stop recording of a macro (keystroke pressings
 sequence)
Ctrl + P  replay macro/pause while processing
Ctrl + ~  show the Console window
Ctrl + H  convert a number under cursor from the decimal numeral system to the hexadimal one and vice versa
Ctrl + Alt + H  convert a model name under cursor to its numeric ID and vice versa
