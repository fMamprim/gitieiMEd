# Guia de Atalhos - GTA SA Modloader

Como as imagens geradas por IA podem não conseguir acomodar todo o texto perfeitamente sem erros ortográficos, preparei este guia definitivo e formatado com todos os atalhos e comandos extraídos diretamente dos arquivos `txt` das suas pastas de mods.

![Cheat Sheet de Atalhos](C:\Users\felip\.gemini\antigravity\brain\1f5621f3-8b24-44dd-bb4e-43100ee82af5\gta_mod_hotkeys_1774819585488.png)

> [!TIP]
> Deixe este guia aberto para rápida consulta enquanto estiver jogando!

## Combinações de Teclas e Ações

| Nome do Mod | Atalho / Comando | O que o mod faz |
| :--- | :--- | :--- |
| **0x858624** | `B + Page Up` / `B + Page Down` | Aumentar / Diminuir o tamanho de algo na tela. |
| **Boxrain** | `W + B` | (Não especificado, ativação do mod). |
| **Carjump** | `Shift` | Faz o carro pular. |
| **Change4Colors** | Digite `COLOR` | Provavelmente abre menu para mudar cores de carros. |
| **Clipboard Cheat** | `Ctrl + V` | Cole cheats copiados da área de transferência (ex: HESOYAM). |
| **Graffiti Anywhere** | `Comandos na Tela` | Permite pichar paredes (selecione a lata de spray). |
| **Insanity** | `R` | Acelera muito rápido (para usar com o carro). |
| **Kamehameha** | `Tab + H` | Lança o golpe Kamehameha. |
| **Myths Maker** | Digite `MYTHS` | Abre o menu de configuração do mod de mitos. |
| **Name Weapon Spawner** | `O + I` ou `W + O` | Permite digitar o nome da arma como no arquivo weapon.dat para spawná-la. |
| **Passenger** | `G` (a pé) / `Y` (no carro) | Entrar no carro como passageiro / Ativar auto-piloto. |
| **PedRain** | `Alt + 1` | Invoca a "chuva de pedestres" (Spawn de pedestres). |
| **Portal Gun** | Digite `PORTAL` | Ativa a arma de portais. |
| **Shoot Stuff** | Digite `SHOOTSTUFF` / Tecla `M` | Função de tiros malucos (A tecla M muda o alvo/pedestre). |
| **Skin Selector (n)** | `Tab + E + Bolinha do mouse` | Abre o menu seletor de skins. |
| **Spawn CJ** | Digite `SPAWNCJ` | Faz o CJ (ou sósia) spawnar. |
| **Spikes Mod** | Tecla `K` / Digite `SPIKES` | Solta tapete de pregos (K funciona em viaturas, SPIKES em qualquer carro). |
| **Vomitar (Ações)** | `Tab + Y` (ou `Z`) | O CJ senta. |
| | `Tab + U` | Fumar baseado. |
| | `Tab + I` | Beber uísque (tiro arremessa a garrafa). |
| | `Tab + O` | Vomitar. |
| | `Tab + P` | Fazer xixi. |
| **Waldrivebyleo** | `4` (Para ir pro teto) / `W + 1` | Andar no teto do carro e opções de driveby. |
| **Walkstyle** | Digite `WALKSTYLE` | Altera a forma do personagem andar. |
