*Incorrect variable name*

	

This error is given when  you use a non-numeric value to name [the local string variables](variables.htm#type) (@s, s$)

	

**Possible solutions:** use correct integer number taking into account the local variables [limitation](SCMHELPGTALimit.htm) of San Andreas.
