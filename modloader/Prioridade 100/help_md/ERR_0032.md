**Sanny Builder Error Messages**
          
      
        
        
          
          

 

	

*Couldn't recognize value*

	        

This error message is  displayed if the compiler was unable to recognize the value of the forth (UNKNOWN_EMPTY_SEGMENT)  or the fifth (UNKNOWN_THREADS_MEMORY) segment of the main.scm.

	        

**Possible solutions:** set the acceptable integer number for this segment.
