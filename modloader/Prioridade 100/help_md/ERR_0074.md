**Sanny Builder Error Messages**
          
      
        
        
          
          

            

            *Enable "Conditions check" option to use this feature*

            

This error message  occurs if you used an IF statement with words **AND** or **OR** with [the option Conditions check](O_101.htm#check) being disabled. This compiler feature can work only when this option is  enabled.

          

  **Possible solutions:** [turn on the option Condition check](O_101.htm#check) via options (F10).
