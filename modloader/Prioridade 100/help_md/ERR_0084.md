**Sanny Builder Error Messages**
          
      
        
        
          
          

            

            *A jump to zero offset found*

            

This error message occurs when your CLEO script has a jump to label placed right in the beginning of the script. The game has a relating bug that makes such jump cause an incorrect scripts work. The effect of this bug is that the game is reloaded (a new game is started again and again).

            

**Possible solutions:** add opcode 0000 in the beginning of the script (before any labels). It will be enough.
