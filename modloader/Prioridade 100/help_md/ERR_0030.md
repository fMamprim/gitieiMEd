**Sanny Builder Error Messages**
          
      
        
        
          
          

 

	        

*The definition of amount expected*

	        

This error message is  given if the compiler expected to find a definition of either missions or  external scripts amount but did not find it. In most cases, it happens due to  incorrect number of elements of the previous header segment of the main.scm.

	        

**Possible solutions:** check if every header segment has correct number of defined elements.
