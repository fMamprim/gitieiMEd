**Sanny Builder Error Messages**
          
      
        
        
          
          

            

            *Incorrect hexadimal value*

            

This error message occurs  in a [HEX..END](hex_end.htm) statement if you used a non-hexadimal symbol. The  hexadimal symbols are Latin letters from A to F, and digits (0..9).

            

**Possible solutions:** correct the mentioned value
