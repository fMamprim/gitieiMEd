*Could not get size of array*

	

This error message is  displayed as you did not specify [the array](arrays.htm#size) size at declaring it in the [VAR..END](variables.htm#VAR_END) construct, or wrote an incorrect value (for example, a string instead  of a number).

	

**Possible solutions:** use the correct integer value
