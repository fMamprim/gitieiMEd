**Sanny  Builder Error Messages**
      
      
        
        
          
          

 

    

*INI file not found*

    

This warning message  occurs when the program cant find [the INI file](GTA_INI.htm), containing the list of opcodes. The compiler work is impossible without  it.

    

**Possible solutions: **either reinstall the program, or  set the correct path to the INI file [via options ](O_101.htm#INI)
