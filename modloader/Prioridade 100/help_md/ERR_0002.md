**Sanny  Builder Error Messages**
      
      
        
        
          
          

 

    

*Unknown array type*

    

[The arrays](arrays.htm) types are strictly limited. If the decompiler did not recognize  the array type compiled in the SCM file, this error is issued. It may happen  because of wrong compiling.

    

**Possible solutions:** toggle debug option [ignore_unknown](console.htm#IGNORE_UNKNOWN) via console.
