*Incorrect counter range*

	

You used incorrect  values for a loop iterations counter. They are being considered as so, if

	

	a) at a [FOR..to](loops.htm#FOR..END) construct  if the initial counter value is greater  than the final one. 

b) at a [FOR..downto](loops.htm#FOR..END) construct  if the final value is greater than the  initial one.

	

**Possible solutions:** consult with [this topic](loops.htm#FOR..END) and set the correct values.
