**Sanny Builder Error Messages**
          
      
        
        
          
          

 

	

*Debug script not found*

	        

This error message is  displayed when the compiler found the special opcode 05B6 with parameter being  greater than the file debug.bin allows. This file contains the debug strings of 128-bytes in length used  by Rockstar Games. These strings are used only in order to produce the SCM  files similarly to original files. 

	        

**Possible solutions:** use an integer number being less than maximum allowed value of 211.
