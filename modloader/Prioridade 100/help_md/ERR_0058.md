**Sanny Builder Error Messages**
          
      
        
        
          
          

            

            *Illegal parameter*

            

The common error message  displayed when you specify an illegal parameter. For example, it occurs, if you  use a number as a result of the functions [Sqr](additional.htm#SQR) or [Random](additional.htm#RANDOM), while the compiler expects to find a variable there.

            

**Possible solutions:** consult with the help and write an accessible parameter.
