*Local variable of a mission is out of range*

	        

This warning message is  shown when you use a number for [a local varaible](variables.htm) name that exceeds the limit for the missions of this game.

	        

**Possible solutions:** use acceptable integer number in accordance with [the local variables limits](SCMHELPGTALimit.htm), or turn off the ranges check via [options](O_101.htm#loc).
