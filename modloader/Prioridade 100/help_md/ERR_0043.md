**Sanny Builder Error Messages**
          
      
        
        
          
          

            

                *Incorrect index name of an array*

            

This error message  occurs when you did not use a variable as an array index but instead used something else (for example, a  number). There are [the indexed variables](arrays.htm#Index) for this purpose.

                

           

 ** ****Possible solutions:** use [a global or a local variable](variables.htm) containing an array index.
