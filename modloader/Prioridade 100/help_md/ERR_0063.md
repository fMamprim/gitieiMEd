**Sanny Builder Error Messages**
          
      
        
        
          
          

            

            *Mission label expected*

            

This error message  occurs if the compiler found a mission label, which must not be placed there  according to the file header. It may also happen if you insert an external  script between the missions. The external scripts must follow all missions.

            

 **Possible solutions:** check out if the missions layout in a source file  corresponds to their declaration order in the header. One of the missions  breaks that order.
