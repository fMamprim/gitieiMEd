    **SannyBuilder**

         Sanny Builder ("Sanny"/"SB") - is a fast and powerful tool designed for the GTA 3D game series (GTA3, VC, SA).  It includes a decompiler, permitting the end-user to quickly decompile the MAIN.SCM file which contains game scripts.  The compiler feature offers a convenient editor with a large number of useful functions such as;  syntax highlighting, error checking, advanced search tools, player coordinates reading, fast movement through code and much more.  Sanny offers an advanced code syntax which is similar to existing programming languages.  This syntax includes changeable classes, keywords and high-level statements.  We recommend you continue reading and fully explore the help section to learn more about SB and its capabilities.  We provide a wealth of information that will help you get started in mission coding.  Now that you have discovered some of the possibilities... 
 Have fun.

**Installation and Updates**

Run the installer and follow its instructions. During installation you could optionally select the game directory you plan to work with, associate the .SCM extension with Sanny Builder and install CLEO 3. All these settings you always can change in the program options. 

To unistall the program, run the file unins000.exe located in its root folder.

Latest versions and updates are always available on the [www.sannybuilder.com](www.sannybuilder.com" target="_blank)

	Command line usage:

\sa - run the SA editor (default)

\vc - run the VC editor 

\gta3 - run  the GTA3 editor

\lcs - run the LCS editor

\vcs - run the VCS editor

\debug - [enables the debug options](console.htm#DEBUG) 

\compile inputfile [outputfile] - run compilation in hidden mode at the program startup

parameters: inputfile outputfile
 

 
For example: \compile C:\myscm.txt C:\myscm.scm   

If there is no outputfile name, the compiler uses  the path based on the name formats. Pay  attention, the source file must have no any errors. If at compilation  there will be errors, they will be  logged in the file compile.log. When compilation ends, the program shuts down.

  You can change the [current edit mode](features.htm#current edit mode) in run-time.
