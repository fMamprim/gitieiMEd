**Sanny Builder Error Messages**
          
      
        
        
          
          

 

	

*Could not recognize a debug script ID*

	        

This error message is  given as the compiler cant recognize the parameter of special opcode 05B6  which is compiler in-built. This opcode defines a number of debug string used  by Rockstar Games in their San Andreas scripts. These strings are used only in  order to produce the SCM files similarly to original files.

	        

**Possible solutions:** use acceptable integer number, or remove this opcode at all.
