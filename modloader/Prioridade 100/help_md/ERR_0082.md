**Sanny Builder Error Messages**
          
      
        
        
          
          

            

            *Incorrect statement*

            

This error is displayed  when the compiler has found a statement, which is not contained inside a major  construct. For example, it happens, if you wrote a word ELSE outside of an [IF..END construct](conditions.htm#THEN).

            

**Possible solutions:** consult with the help topics, and write an acceptable construct.
