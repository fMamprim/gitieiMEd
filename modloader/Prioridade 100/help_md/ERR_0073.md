**Sanny Builder Error Messages**
          
      
        
        
          
          

            

            *Incorrect number of the conditions*

            

              This error message is  displayed when you used only one condition in the [IF..END](conditions.htm#IF_AND) statement but for all that there is a word **AND** or **OR**. These words  are only acceptable in a case of checking the several conditions at same time.

            

**Possible solutions:** correct this statement: either use several conditions, or remove the word **AND** or **OR**.
