*Couldn't get a local variable*

	        

This error message  occurs if the compiler was unable to recognize the number of [a local varaible](variables.htm) being its name. It happens when you did not use an  integer number, but, for example, a string or a floating-point value. 

	        

**Possible solutions:** set the correct number for a local variable name.
