*Not enough actual parameters*

            

The compiler expected to  find certain number of parameters but failed. Either the line may have  parameters less than expected, or some of them are unacceptable. The expected number  of parameters is set in the [INI file](GTA_INI.htm) and can be displayed in the status bar at the option [Show opcode info](features.htm#IDE) being turned on.

            

**Possible solutions:** write the required number of parameters.
