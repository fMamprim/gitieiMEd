**Sanny Builder Error Messages**
          
      
        
        
          
          

 

            

*Couldn't recognize segment element*

            

This error occurs when  the compiler cant recognize one of the elements either of a mission segment or  an external scripts segment: mission or script label, number of mission. It may  happen if you used a string when an integer number is expected.

            

**Possible solutions:** use a correct element value.
