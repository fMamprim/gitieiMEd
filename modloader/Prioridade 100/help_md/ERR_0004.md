*Unknown parameter type*

	

An opcode parameter can be  only one of the pre-defined types. The error occurs if the decompiler can not find out what  this parameter is type of, or its ID is unknown. It also occurs if the file was  compiled incorrectly, or the number of parameters for an opcode in SCM does not  match the number in the INI. 

	

**Possible solutions:** toggle debug option [ignore_unknown](console.htm#IGNORE_UNKNOWN) via console.
