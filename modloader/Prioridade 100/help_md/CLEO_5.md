**Sanny Builder Error Messages**
      
      
        
        
          
          

 

    

*CLEO library not found*

    

This error message is  displayed, if you used an opcode that requires the CLEO library to be  installed. The program either not found needed files or the existed files is  outdated.

    

**Possible solutions:** install CLEO by clicking the word CLEO on the  bottom panel.
