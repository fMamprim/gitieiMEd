**Sanny Builder Error Messages**
          
      
        
        
          
          

 

	

*Thread not found*

	

This error occurs when  the decompiler cant find the beginning of the mission or external script where  the header defines them. More often, it happens when the script.img is used,  internal offsets of which is turned out to be different from those written in  the main.scm header.

	

**Possible solutions:** toggle debug option [ignore_unknown](console.htm#IGNORE_UNKNOWN) via console.
