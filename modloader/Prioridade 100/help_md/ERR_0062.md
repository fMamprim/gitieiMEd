**Sanny Builder Error Messages**
          
      
        
        
          
          

            

            *IDE file not found*
            

If the program failed to  load a required IDE file in the game folder data, this message is displayed.  The error may occur, for example, if the file default.dat (SA) contains a link  to a non-existent IDE file.

            

**Possible solutions:** check out the existence of the mentioned file.
