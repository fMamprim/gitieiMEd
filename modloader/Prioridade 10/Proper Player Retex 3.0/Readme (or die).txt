=======   MixMods.com.br   ======= - Best visualization with monospaced fonts, like "Consolas".


------- Instructions:

Extract the folder "Proper Player Retex" to your Modloader folder.

IF YOU ALREADY HAVE AN OLD VERSION, DELETE IT BEFORE INSTALLING THIS NEW ONE!

-- Essentials Pack download: https://www.mixmods.com.br/2019/06/sa-essentials-pack/


  Since this mod uses player.img, it will always be loaded on lowest priority:
  https://www.mixmods.com.br/2015/07/tutorial-dicas-tudo-sobre-modloader-gta/#Priority
  So any clothing mod will replace the clothes of this mod.

  This mod is compatible with other clothing mods for the original CJ, however, with 1024px body resolution.
  That is, if you try to install, for example, a shirt with a resolution of 512 it will cause a crash, it is required to be 1024.
